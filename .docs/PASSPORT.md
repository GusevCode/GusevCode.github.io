# 3. Концепция проекта

## Общая идея

Проект представляет собой экспертную систему, которая помогает пользователю выбрать наиболее подходящий газированный напиток на основе его индивидуальных предпочтений.

Современный рынок газированных напитков содержит большое количество вариантов: классические напитки, версии без сахара, напитки с различными вкусами, а также альтернативные бренды.

Выбор напитка зависит от множества факторов:

- отношение к сахару;
- предпочтение классического или необычного вкуса;
- необходимость низкой калорийности;
- ситуация использования;
- сочетание с едой;
- уровень желаемой газированности;
- ценовые предпочтения.

Экспертная система анализирует ответы пользователя, сопоставляет их с характеристиками напитков из базы знаний и формирует персональный рейтинг.

# 7. Атрибуты объектов

Каждый напиток описывается набором характеристик.

| Атрибут | Описание |
|---|---|
| Уровень сладости | Степень сладости напитка |

| Калорийность | Энергетическая ценность |

| Газированность | Интенсивность газации |
| Сочетаемость с едой | Подходит ли напиток к различным блюдам |
| Подходит для компании | Возможность использования на мероприятиях |
| Повседневное употребление | Подходит ли для регулярного употребления |
| Популярность | Распространенность напитка |
| Цена | Стоимость продукта |
| Насыщенность вкуса | Интенсивность вкусовых ощущений |

# 9. База знаний

База знаний содержит:

1. Описание объектов предметной области.
2. Набор характеристик напитков.
3. Правила сопоставления предпочтений пользователя с объектами.

Примеры экспертных правил:

```
ЕСЛИ пользователь предпочитает классический вкус

```

```

```

```

ТО увеличить рейтинг напитков с высокой газированностью
```

# 10. Механизм логического вывода

Работа экспертной системы:

1. Пользователь отвечает на вопросы.
2. Ответы сохраняются в рабочей базе данных.
3. Полученные параметры анализируются.
4. Каждый параметр сравнивается с атрибутами объектов.
5. Объектам начисляются баллы за совпадения.
6. Выполняется сортировка объектов по итоговому рейтингу.
7. Пользователь получает список рекомендаций.

Пример результата:

```
1. Coca-Cola Original Taste — 94 балла
2. Coca-Cola Zero Sugar — 86 баллов
3. Pepsi — 79 баллов
4. Добрый Cola — 74 балла
5. Черноголовка Cola — 68 баллов
```
